# TOM Pharmacy Business Library

Open, reusable pharmacy **business** documents for pharmacists building and running practices.

## Preview release (2026-09-19)

First wave: **80 documents** across collections LIB01–03 and LIB05–11 (opportunity, ownership, community ops, payment, workforce, inventory, privacy, quality, client development, ASC consulting).

Each document follows a fixed format: purpose, audience, tools, core content, setting branches, Texas adaptation checklist, numbered Sources, and Unresolved/held claims.

## Important

- **Not legal or clinical advice.** Held claims must stay held until pharmacist/counsel review.
- **CC BY 4.0** for original TOM prose/templates in this preview (see `LICENSE`). Trademarks excluded.
- Companion research dossiers and claim ledgers live beside topics in the authoring workspace; this repo ships the `final/` reader documents.
