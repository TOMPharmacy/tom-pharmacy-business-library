## Setting branches
Skip any branch that does not apply to your operation. Synthetic examples only — no real patient or facility identifiers.

### Community (independent / retail)
Each Class A location needs its own license; PIC generally full-time for one Class A with narrow dual-site exceptions [1][2]. Do not treat an agency staffing contract as a pharmacy license. Synthetic example: *Site Oak* and *Site Pine* under one FEIN still need separate licenses and PIC accountability maps.

### ASC / consulting pharmacy
If the portfolio includes Class C / ASC consulting, apply Class C PIC bed/facility limits and written agreements [3]. Agency visit coverage ≠ PIC designation unless the written agreement and board rules say so.

### Clinic-embedded
Clarify whether the clinic hosts a licensed pharmacy vs a pharmacist employee of the clinic. Entity boundaries drive BAAs, DEA, and billing — verify before scaling agency staffing into clinics.

### Specialty / infusion / compounding
Sterile subclass and 503A/503B paths multiply per site. Centralize SOPs only after confirming each site’s license class and sterile privileges. Diversion controls remain site-local [7][10].

### Telepharmacy / delivery
Remote verification and central fill do not erase per-location license/PIC duties. Document which site owns the prescription record and which PIC is accountable for final check.

## Local adaptation — Texas verification checklist
- [ ] Confirm each principal place of business has its own Texas pharmacy license [1].
- [ ] Map PIC assignments against Class A §291.32 one-pharmacy rule and any emergency dual-site facts [2].
- [ ] If Class C sites included: apply ≤3 facilities / 150 beds (≤100-bed) or continuous supervision (≥101-bed) rules [3].
- [ ] File PIC change notices within 10 days via TSBP forms hub [4].
- [ ] Execute BAAs wherever agency workforce creates/receives PHI for a CE client [5].
- [ ] Confirm DEA registration posture per location handling controlled substances [6][7].
